# 参数与素材边界

## 图像采样

附带素材是白底黑灰线稿。离屏绘制宽度为 640px，边界检测间距为 2px，采样间距为 2.8px；按红通道的深浅筛选，深色线条保留更多点。确定性 hash 避免每次构建出现不同的随机布局。

更换透明 PNG 时加入 alpha 过滤；更换彩色图时改用亮度计算。直接使用复杂照片通常难以形成清楚轮廓，优先先转为高对比线稿。不要把透明区域的黑色 RGB 误当作有效线条。

## 构图

| 参数 | 作用 |
|---|---|
| `corner` | 右下布袋和左上布纹 |
| `weave` | 两片程序生成的布纹 |
| `diagonal` | 默认大幅斜向布袋 |
| 中心 | `width × 0.55`、`height × 0.54` |
| 旋转 | `-0.94` 弧度 |
| 构图透明度 | `0.79` |
| 布袋尺寸 | `min(height × 1.6, width × (mobile ? 1.5 : 1.14))` |

`mobile` 指不超过 767px。手机系数曾为 `1.95`，最终缩小为 `1.5`；高度上限也会约束实际尺寸。

中央 `.text-center` 内容定义椭圆避让区。手机横向半径为 `width × 0.42`，桌面为 `width × 0.30`，上限 450px；渐隐边界避免文字背景出现硬切口。

## 鼠标交互

作用半径为 `min(150px, width × 0.16)`。靠近时沿远离鼠标的方向推开，同时提高透明度，半径最多约扩大一倍；离开、指针取消或失焦后回位。平滑系数为 `1 - exp(-7 × dt)`，按经过的时间计算。

## 手机自动扫光

| 参数 | 默认值 |
|---|---|
| 周期 | 8s |
| 扫描 | 5.8s，其余时间恢复 |
| 斜带坐标 | `ry + rx × 0.22` |
| 光带宽度 | `max(44, min(70, width × 0.14))` |
| 激活曲线 | `exp(-(distance / scanBand)² × 2)` |
| 位移目标 | `heat × 16px`，由 hash 决定方向 |
| 自动模式点数上限 | 4,400 |
| 其他模式点数上限 | 10,500 |
| 自动模式 DPR 上限 | 1.5 |
| 其他模式 DPR 上限 | 1.75 |
| 自动模式目标帧率 | 30fps |

斜带逐点激活，不需要额外绘制实体光带。只有窄屏、粗指针或无悬停设备进入自动模式；减少动态效果优先。

## 生命周期

保留可见性观察、后台暂停、恢复时重置帧时间、100ms 尺寸变化防抖、静止停止绘制，以及卸载后的观察器 / 监听器 / 计时器 / 图片回调清理。不要以持续空转动画代替桌面静止时停止。
